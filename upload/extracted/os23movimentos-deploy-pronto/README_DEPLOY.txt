DEPLOY-READY STATIC SITE
=========================

Para onde enviar:
- Netlify: arraste a pasta inteira para o deploy manual
- Vercel: importe como projeto estático
- Hospedagem comum: envie todos os arquivos para public_html
- GitHub Pages: push para repo e ative Pages

Arquivos principais:
- index.html     → Landing page premium cinematográfica
- logo.svg       → Favicon com identidade gold
- robots.txt     → SEO crawlers
- netlify.toml   → Config Netlify
- vercel.json    → Config Vercel
- _redirects     → Netlify redirects
- lovable-uploads/ → Imagens do produto
- videos/        → Pasta para os 3 vídeos (veja README dentro)

VÍDEOS:
Coloque os 3 vídeos na pasta "videos/" com os nomes:
  1. hero.mp4         → Seção Hero (background fullscreen)
  2. transformation.mp4 → Seção Transformação
  3. offer.mp4        → Seção Oferta (background)

Se os vídeos não estiverem presentes, a página usa as imagens
como fallback (poster images).
